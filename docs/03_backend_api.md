# Backend API

Point d'entrée :

```txt
backend/app/main.py
```

Runtime compatible :

```txt
backend/app/app_runtime.py
```

Routes importantes :

- `/auth/otp/start`
- `/auth/otp/verify`
- `/auth/me/profile`
- `/auth/me/avatar`
- `/conversations`
- `/conversations/private`
- `/conversations/group`
- `/statuses`
- `/tracking`
- `/ws`
