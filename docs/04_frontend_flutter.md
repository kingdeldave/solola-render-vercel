# Frontend Flutter

Point d'entrée :

```txt
frontend_flutter/lib/main.dart
```

Structure :

- `app.dart` : thème, session et page racine.
- `services/api_client.dart` : HTTP.
- `services/websocket_service.dart` : prévu pour extraire le WebSocket.
- `services/pin_crypto.dart` : chiffrement AES-GCM.
- `pages/auth_page.dart` : inscription OTP.
- `pages/home_page.dart` : interface principale.
- `widgets/` : composants visuels.
- `dialogs/` : boîtes de dialogue.
